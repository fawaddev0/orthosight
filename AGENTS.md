# OrthoSight Monorepo — Global Agent Instructions

## 1. Project Overview
OrthoSight is an Orthopedic monitoring tool to help people with their physio conditions (e.g., Frozen Shoulder, Rotator Cuff disorders) without going through hectic process of booking appointments with physiotherapists, travelling, and waiting in long queues.

It diagnoses, recommends, and guide patients in workouts to fix their physio conditions. It provides gamified workout solutions for increased patient engagement and fun experience.

This monorepo houses the core decision engine, backend services, web showcase, and mobile client applications:
* **`data/`**: Read-only clinical decision tree definitions (`layer1.json` through `layer4.json`).
* **`backend/`**: Python engine (`DecisionTree`), FastAPI backend, and RAG pipeline integration.
* **`web/`**: Next.js web application for the marketing landing page and interactive tree explorer.
* **`mobile/`**: React Native mobile app for clinical end-users.

## 3. Mandatory Monorepo Rules

1. **DATA IMMUTABILITY (STRICT):**
   * **DO NOT** edit, mutate, overwrite, rename, reformat, or delete `data/layer1.json`, `data/layer2.json`, `data/layer3.json`, or `data/layer4.json`.
   * Treat all `layer*.json` files strictly as **read-only** datasets.
   * File access in code must use read-only modes (e.g., `"r"` mode or `Path.read_text()`).

2. **STRICT TYPING & ZERO UNTYPED DATA:**
   * **Python:** `typing.Any` is strictly banned across all python files. Use explicit primitive types, `Union`, `Optional`, generics, or Pydantic models.
   * **TypeScript:** The `any` keyword is strictly banned in all `.ts` and `.tsx` files. Use explicit interfaces, types, or generics.

3. **SCOPE BOUNDARIES:**
   * When working inside `backend/`, follow `backend/AGENTS.md`.
   * When working inside `web/`, follow `web/AGENTS.md`.
   * When working inside `mobile/`, follow `mobile/AGENTS.md`.
   * Do not import frontend files into the backend or vice-versa.

---

## 4. Cross-Service Contracts
* **Engine Source of Truth:** `backend/src/decision_tree/core.py` houses the primary `DecisionTree` engine class. Both the FastAPI app and the Python RAG pipeline import directly from this package.
* **API Schema Synchronization:** Frontend web and mobile types must be aligned with the OpenAPI specification generated by the FastAPI backend at `/openapi.json`.
* **API Route Division:** REST API routes are partitioned under `/api/v1/web` and `/api/v1/mobile`.
